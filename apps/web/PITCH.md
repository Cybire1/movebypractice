# Glide - Feature Overview

## The Problem

Move is a powerful smart contract language designed for safety and expressiveness, but it lacks interactive learning resources. Developers who want to build on Sui face a steep onboarding curve: scattered documentation, no hands-on practice environments, and no structured path from beginner to production-ready. The result is slower ecosystem growth and a smaller developer pool than Sui deserves.

## Our Solution

**Glide** is the interactive platform that teaches Move and Sui development through hands-on practice. Instead of passive tutorials or dense documentation, Glide drops you into a live code editor from lesson one and guides you through progressively challenging exercises until you can build and deploy real applications on Sui.

---

## Core Features

### Interactive Learning Paths

- **15 Progressive Lessons** organized into two tracks: 7 Move fundamentals and 8 Sui Messaging SDK modules
- **Multi-phase learning**: Teaching, Exercises, Quiz, and Free Practice in every lesson
- **Smart UI**: The code editor appears only when you need it, keeping focus on the current task
- **Instant feedback** on every exercise so you never wait to know if you got it right

### Live Code Environment

- **Monaco Editor** with a VS Code-grade editing experience
- **Move syntax highlighting** purpose-built for the language
- **Instant feedback** with helpful error messages and suggestions
- **No setup required** - compile and test directly in your browser

### 4 Exercise Types

1. **Code Completion** - Fill in the blanks to complete Move programs
2. **Bug Fix** - Debug broken code to learn best practices and common pitfalls
3. **Multiple Choice** - Test conceptual understanding of Move and Sui primitives
4. **Output Prediction** - Read code and predict what it produces to build mental models

### Gamification System

- **XP and Levels** - Earn points for every completed exercise, level up at 1000 XP thresholds
- **Achievement Badges** - Unlock rewards for milestones like first deploy, streak records, and track completions
- **Streak Counter** - Build daily learning habits with a visible streak tracker
- **Progress Dashboard** - Track completed lessons, time spent, attempt history, and overall stats

### AI Tutor Assistant

- **Context-aware help** based on your current lesson and exercise
- **On-demand explanations** of Move concepts in plain language
- **Personalized hints** when you are stuck on an exercise
- **Code walkthroughs** that break down solutions step by step

## Learning Journey

### Beginner (Lessons 1-3)

- Hello Move - Your first Move module
- Types and Variables - Integers, booleans, addresses, vectors
- Control Flow - Conditionals, loops, and expressions

### Intermediate (Lessons 4-5)

- Structs and Objects - Custom types and Sui object model
- Collections - Vectors, tables, and dynamic fields

### Advanced (Lessons 6-7)

- Ownership and Transfer - Move's ownership system, transfer policies, and shared objects
- Generics and Patterns - Type parameters, abilities, and reusable module patterns

### Applied (Lessons 8-15)

- **Sui Messaging SDK Track** - Eight lessons covering real-world application development on Sui, from message creation to on-chain communication patterns

The Sui ecosystem is growing rapidly. New developers are entering the space daily, drawn by Move's safety guarantees and Sui's performance. Yet there is no interactive Move learning platform available today. Existing resources are limited to static documentation, blog posts, and scattered example code. Glide fills this gap with a purpose-built, interactive learning experience that turns curious developers into productive Sui builders.
